# Island Forge Boot-Camp Syllabus  
**Junior & Mid-Level Cohorts – Version 1.1**  
_Date: 1 May 2025_

---

## Why this Boot-Camp?
The Island Forge talent pipeline converts English-speaking Caribbean graduates into production-ready engineers for US / UK / Canadian clients inside ten weeks. All curricula align with our seven-tier certification ladder and are benchmarked against Bay-Area coding standards.

### Success Metrics
- **100 %** GitHub Classroom submission rate  
- **≥ 80 %** of the cohort pass the exam on first attempt  
- Client **NPS ≥ 8.5** after 90 days billable  
- **≥ 40-50 %** female participation  

---

## Section 1 — Junior Dev-to-Hire Boot-Camp (6 Weeks)

**Objective:** Convert early-career graduates and self-taught coders into billable junior engineers within ten weeks.  
**Format:** Five weeks of classroom + lab, followed by exam and live demo day. Daily stand-ups, pair programming, and continuous assessment via GitHub Classroom.

| Week | Key Focus          | Core Objectives                                                                     | Required Deliverables                               |
|------|-------------------|--------------------------------------------------------------------------------------|-----------------------------------------------------|
| 1    | Foundations       | Git workflow • Linux CLI • TypeScript essentials • Agile rituals                     | Git kata + TypeScript lint-passing lab             |
| 2    | Frontend Basics   | React Native & Expo primer • Jest unit tests                                         | Build & test a Todo-list mobile UI                 |
| 3    | Backend API       | FastAPI CRUD • SQLite • OpenAPI docs                                                 | Deploy API locally with Docker Compose             |
| 4    | Security & Auth   | OWASP Top-10 • JWT auth • Intro SOC-2 controls                                       | Secure API with JWT • Basic threat-model write-up  |
| 5    | Team Project      | Mobile chatbot integration • Code-review etiquette                                   | Group demo (alpha) & retrospective                 |
| 6    | Exam & Demo       | 4-hour supervised lab • Panel demo                                                   | Pass/fail exam • **Credly Junior Badge**           |

---

## Section 2 — Mid-Level Accelerator (12 Weeks)

**Objective:** Elevate juniors to autonomous contributors who can own micro-services, CI/CD pipelines, and observability dashboards.  
**Format:** Six weeks of advanced labs, then six weeks embedded on live client projects under a senior mentor.

| Week  | Key Focus               | Core Objectives                                                              | Required Deliverables                               |
|-------|-------------------------|------------------------------------------------------------------------------|-----------------------------------------------------|
| 1     | Legacy → TS Strict      | Refactor JS repo • Enforce ESLint / Prettier                                 | 100 % type-safe PR merged                           |
| 2     | CI/CD Fundamentals      | GitHub Actions • Multi-stage Docker builds • Playwright E2E                  | Green pipeline & artifact registry online           |
| 3     | Observability           | Prometheus • Grafana • Datadog • SLO basics                                  | Custom latency & error-rate dashboard               |
| 4     | Cloud Resiliency        | Chaos Monkey • Rollbacks • Blue/Green deploy                                 | Run rollback demo & post-mortem                     |
| 5     | Intro to RAG            | ChromaDB embeddings • LangChain • Privacy pitfalls                           | RAG POC with redaction checks                       |
| 6     | FinOps & Rightsizing    | Cost optimisation • K8s resource quotas                                      | Savings report & Terraform PR                       |
| 7-12  | Client Shadowing        | Embedded on billable codebase • Weekly mentor reviews                        | Close feature tickets • Client NPS ≥ 8.5 • 20-min demo |
| 12    | Exam & Portfolio        | System-design panel • 6-hour sprint                                          | **Credly Mid-Level Badge**                          |

---

## Assessment & Certification

- **Passing threshold:** 75 % combined lab score **and** panel approval  
- Up to **two re-take** opportunities within 30 days  
- Credly badges issued automatically via GitHub Actions on pass event  
- Mid-Level graduates become **Senior-track eligible** after six months billable
